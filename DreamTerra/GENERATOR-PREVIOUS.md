# DreamTerra · 山川世界

织梦内的 TerraGenesis 地图入口。核心实现位于本目录；旧 civ 世界继续由原生宿主读取，其原生地形细节与本轮已完成的城镇分级保持不变。不修改城镇内部地图。

启动织梦后，在世界地图上方选择 **DreamTerra 山川世界 → 新建世界 → 生成并保存**。生成完成后可缩放、拖动、点击查看城址依据；**从此启程**创建绑定这份世界的新旅程。再次启动后可从列表读取已保存世界，不重新生成。已有运行中的织梦服务需要重启以加载新增接口。

## 实现与数据

- `generation.py`：米制地图适配；直接调用 TerraGenesis 的 `world_water_layout.layout_field`、概览连续地形/山脊算法与 `surface_rivers.drainage.route/accumulate`，不移入其独立三大陆世界。默认源工程是同级的 `山川形意Terragenesis`；其他位置使用环境变量 `DREAMTERRA_SOURCE` 指定。
- `service.py`：生成成功后才登记，保存 JSON + NPZ；作者接口与玩家遮罩接口分开；接入现有 `Runtime.move`、旅程时钟及存档。
- `static/`：墨绿、米白地图界面。地形色层上叠加由真实高程提取的等高线、真实河流与路网、跨河符号和聚落。缩放只变更渲染，不发起生成请求。
- `host-patch/`：织梦宿主改动副本及接口补丁。civ 上游宿主未改，其 `host.tsx` 与原有仓内补丁副本的 SHA-256 一致。
- `evidence/`：真实浏览器截图、生成对照与跨城旅行结果。`artifacts/` 为可重新生成的运行数据，不作为源代码提交。

坐标为有限平面，x 向东、z 向南，点坐标以 km 表示，高程以 m 表示；1 km 为 cell-center 采样，不是建筑级地形。水文在整个生成区域上一次计算，区域边界的出流明确记录 `external`；湖水面与床面分开保存。河流量为 m³/s，绝不直接当作 civ 的 flux。

为适配既有玩家画布，故事中的显示坐标使用 `[x/111, -z/111]` 的线性框；返回 `projection.scheme=finite_planar`。这些值不参与大圆距离计算。道路距离由原始公里折线累计；坡度、洪泛区及桥/渡口附加代价决定旅行时间。

旧 civ 的地块道路寻路与旅行链继续复用。有限平面新世界无法直接使用球面 civ 邻接图，因此新道路以同类通行代价建立栅格邻接，调用已安装 SciPy 的最短路和最小生成树；不把两种坐标系混为一套。没有跨海航线的新孤立陆块会明确标注“尚无交通连接”。

## 参数与复现

| 参数 | 默认 | 范围 / 含义 |
|---|---:|---|
| 种子 | 20261020 | 0—2147483647；不同用途派生稳定子种子 |
| 区域边长 | 512 km | 128—1024 km；本轮完整验收 512 km，旅行验收 128 km |
| 水域比例 | 0.38 | 0.1—0.8；宏观海陆目标，最终湖泊另由汇流产生 |
| 河网密度 | 1.5 | 0.5—4；成河门槛为 `1.5 / 密度` m³/s |
| 降雨 | 1 | 0.3—2 倍；影响气候、径流与适居度 |
| 山脉 | 1 | 0.2—2 倍；改变连续山脊的高程 |
| 聚落数量 | 48 | 12—64；目标数量，土地不适宜时实际可能更少 |
| 当前年份 | 100 | 人口资料的静态年份；不引入文明历史推演 |

保存种子、全部参数、派生子种子、源文件指纹、数值库版本、生成版本和关键数组摘要。生成版本为 `dreamterra-map-1+指纹`，指纹包括 TerraGenesis 源码与数值运行库：不同库版本有已观察到的浮点末位差异，不能以同一生成版本伪称字节一致。正常读取存档不依赖重新运行源生成器。

人口分级为少量首都/城市、较多镇村，选址先排除海湖、明显陡坡与湿地，再考虑淡水距离、平地、港湾及森林/丘陵资源代理。道路在选址后生成；尚未进行道路建成后的城镇迁移或增长模拟。人口是所选年份的静态记录。资源代理不是独立矿产调查数据。

## 验证结果（2026-10-30）

机器：Windows 11，AMD Ryzen 7 7735HS，约 15 GiB 可用物理内存总量，Edge 156；工程 Python 3.12.14。

- 512×512 km / 262,144 个样本：48 座聚落、47 条道路、2,578 段河道、209 km² 湿地、7,419 km² 洪泛候选区。浏览器点击生成至出图约 **9.33 秒**。
- 同种子、同配方（包括 JSON 参数往返）、同生成版本：世界对象及所有关键数组一致。密度 0.5→1.5 时河段 1,132→2,578，高程与下游接收数组不变。
- 255 处道路跨河记录；道路地块连续，不穿海湖，城址不在水面或明显陡坡。汇流收支误差约 4.5×10⁻¹³ m³/s。
- 总览 4 座重要城市；区域/局部按视口分别绘制 4/3 座（缩放时视口变小，不能据此要求数量单调增加）。局部截图可见镇、村及桥渡。复位恢复总览；刷新后读取同一已保存世界。
- 本次记录的单帧绘制：总览 1.7 ms，区域 3.5 ms，局部 3.4 ms；这是采样帧，不是完整帧率或 P95 基准。390 px 窄屏通过，浏览器页面异常 0。
- 真实跨城：11.66 km，4 小时；时钟 8→12，角色位置与重读存档一致。玩家只见 3 个已知地点，PNG 由服务器遮罩；浏览器玩家阶段作者接口请求为 0。
- **24 项相关测试通过，Ruff 通过**：新生成/旅行测试，以及原生世界、原有 civ 旅行、空世界启动测试。
- `tests/test_play_map.py` 有 **23 个既有夹具初始化错误**：测试假设空数据库会自动加载旧故事包，但当前实现已经取消该行为。未修改这组无关夹具，也不声称整套旧测试全绿。

复跑：`uv sync --extra dev`；`.venv/Scripts/python.exe -m pytest DreamTerra/tests tests/test_native_worlds.py tests/test_civ_exploration.py tests/test_empty_world_startup.py`。浏览器台本：先以临时数据库运行 `tools/serve_for_probe.py 8768 <临时目录>`，再执行 `node DreamTerra/tests/browser.cjs`。不会写正式旅程数据库。

## 后续扩展成本

- 峡谷/山口：中等；需要横断面或鞍点判别、连通通道验证、候选去重和地点交互。目前候选字段只是输入。
- 瀑布：中等；需要河段局部落差、岩性或陡坎资料；1 km 地形不能认证具体瀑布高度。还需阻航/绕行规则。
- 喀斯特：较高；需要碳酸盐岩分布、溶蚀/地下排水和地表洼地一致性，不能仅凭湿润度生成。
- 洞穴：高；需要独立地下空间拓扑、入口与连通关系、垂向坐标和地下旅行；高度场不能表示洞穴体积。

复用以本机源工程模块调用为主，没有复制整个 TerraGenesis 仓库或覆盖其工作区。civ 第三方许可说明继续见仓库 `THIRD_PARTY_NOTICES.md`。
