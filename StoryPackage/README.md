# StoryPackage · 文档就是故事包来源

当前启用：玄陆。程序启动、里层生成、新建旅程和“从文件夹重新读取”会读取该目录；不会把整个目录全文送给模型。

- 玄陆/总概.md：总概，固定放在提示词前部。
- 玄陆/知识点/分类/*.md：各个知识点；文件顶部 JSON 是 ID、标题、关键词、权限与来源状态，代码块后是可直接编辑的正文。
- 玄陆/story.json：地图、事件、物品、规则及角色包引用；角色本人仍独立存放在 character_packages。
- 玄陆/生成记录/旅程/*.md：各旅程实际显示过的原文摘录、关键词和摘要；只在原旅程检索，不写成公共世界真相。
- 玄陆/生成记录/里层草稿/*.md：里层模型生成材料，仅供作者查看，不进入玩家记录簿。
- 玄陆/历史文档：撤下的知识点。迁移前故事包备份.json 保留原始数据。

所有源文件均为 UTF-8。Markdown 是直接可读、可修改的正式文档；无需把 Word 反复转换为 JSON。新建知识点可复制一个现有文件，使用唯一英文 ID，修改标题、关键词、正文及 public/author 可见性。public 表示允许叙述者使用的世界常识，不表示玩家已经读过。

修改后点击里层“从文件夹重新读取”。结构错误会明确报错。通过校验的内容形成 SQLite 版本快照；数据库服务于旧存档、回滚和运行状态，世界设定的编辑来源是本文件夹。已有旅程绑定原版，新旅程使用新版本。请勿在应用正保存故事包时同时手改同一个文件。

生成检索：先过滤可见性、角色、地点与解锁条件，再按关键词和地点匹配，固定 ID 打破同分；至多6点、3600字符，缺少依赖时不选入。不相关点不注入；这是本地关键词检索，不是语义向量搜索。总概只保留跨场景必须遵守的基础，其他详细规则需依赖或关键词触发。

摘要采用本地原文摘录，无额外模型调用；保留完整段落作证据，通常取前两句作预览，包含否定、传闻或未核实等限定时保留整段，关键词辅助检索。它不会自主核实或消歧。记录簿从存档中实际回复重建，事件回滚后同步移除未来记录；它不会因提及某个人名便展开这个人的后台档案。
