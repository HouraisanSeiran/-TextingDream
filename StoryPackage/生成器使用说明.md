# 架空世界观与世界生成器

左侧新增两个作者入口，使用 API 配置中的 DeepSeek 或其他兼容模型。离线时返回可编辑模板，并明确标记；不会假装已理解自由要求。

1. 在“架空世界观生成器”填写名称、时代或风格参考、具体要求。生成短总概及4—24个分类知识点，区分 public 常识与 author 隐藏信息。预览后可展开 JSON 编辑并校验。
2. 点击“保存到 StoryPackage”，得到独立的 `世界观_<ID>/总概.md` 与 `知识点/*.md`。它是可复用的基础，不单独宣称已具备可玩事件。
3. 点击“用于生成世界”，或在“架空世界生成器”选择已有草稿/当前故事包的世界观。已保存的世界观会重新读取文件夹中的总概和知识点，接受手动文档修改。
4. 生成2—5座城市，以及地区、地形、势力、公开发现、隐藏冲突、物品和主角/向导。每座城市对应一个主要场景，城市按列表顺序构成双向连接的旅行路线。
5. 审阅后保存，得到 `世界_<ID>/story.json`、总概及分类知识文档；角色包独立写入工程的 `character_packages/characters_<ID>.json`。
6. 在世界生成器下方“可用故事包”点击启用，再新建旅程。原故事包和旧旅程保持独立；重启会恢复所选故事包。里层依然可以编辑知识点、角色和事件。

每个生成步骤只调用一次模型，不自动付费重试。单次输出上限可设1500—8000 token，默认4000；三至五城较详实的生成可适当提高。输出截断、字段不符或数量不符会报错，不替换现有故事包。源请求、响应及用量在“模型输入输出”的对应生成器筛选中查看。

世界编译器负责生成有效ID、地点引用、角色绑定、双向路线、事件后继和明确结束动作，避免模型自行拼接无法运行的事件图。事件默认支持自由对话、当地调查和结束，首城另有领取行路册的动作；这是一套可继续扩展的可玩起点，不是自动生成无限开放世界。秘密不进入公开字段和记录簿；AI若在公开描述里自行泄露了秘密，结构校验无法语义判断，作者仍应检查公开发现。

世界观全部保存在文档中，实际生成只用总概和匹配知识点。历史参考是创作输入，不代表模型进行了史料检索。坐标使用现有世界底图上的示意经纬度；本功能生成的是世界内容与城市路线，不生成地形栅格或新的大陆图片。
