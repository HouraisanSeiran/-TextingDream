# east-base · 东方玄幻城镇基础素材（3/4 斜俯视，尚未接入游戏）

规范：`docs/town-art-spec.md`。画法与 `fog-brushes/fog-xiangyun.js` 的 PAL 统一：国潮不透明平涂 + 金线勾边 + 叠晕，不用渐变 / 模糊。全部是原创程序化路径，随机都用 mulberry32 种子。

## 文件

| 文件 | 内容 |
|---|---|
| `east-core.js` | 共用画笔：色板、投影公式（屏幕 y = g − z·0.85）、屋顶（`roofEW` 硬山/悬山/庑殿/歇山/卷棚，`roofNS` 山面朝南，`roofPyr` 攒尖）、立面、门窗、灯笼、树、竹，`symbol()` 包装 |
| `houses-a.js` | 四合院、三合院、徽派马头墙民居、吊脚楼、客家土楼 + 共用部件（开间、院墙、马头墙、栏杆、披檐） |
| `houses-b.js` | 两层铺面、茅舍、硬山小宅、竹楼、窑洞、碉楼 |
| `houses-c.js` | 园林宅院、歇山大宅、渔家棚屋、悬山农舍、卷棚小筑 |
| `tiles.js` | 道路三档 × 16 双网格瓦片、城墙 16 张、城门楼 gate-h / gate-v、角楼两种 |
| `east-base.js` | 汇总入口：浏览器挂 `window.TownArt_eastBase`，Node 用 `module.exports`；`buildAll()` |
| `build.js` | `node build.js` 生成 `sprite.svg`、`meta.json`，同时自检 id 唯一、内部 id 带前缀、meta↔symbol 一一对应、上伸 ≤ 144 |
| `preview.html` + `preview-scenes.js` | 离线预览（file:// 直接开）：民居图册、16 瓦片表、叠加件、拼接验证、街巷示意 |

浏览器引入顺序：`east-core.js → houses-a.js → houses-b.js → houses-c.js → tiles.js → east-base.js`。
注意：内联 sprite 不能放进 `display:none` 的 `<svg>`，否则 Chrome/Edge 里 symbol 内的 clipPath 失效（瓦面、路面纹理会溢出）；用 0×0 绝对定位的 svg。

## 双网格瓦片

- 道路：`east-common-road-{dirt|stone|highway}-<NW NE SW SE>`，各 16 张（0000 为透明占位）。黄土路（土粒、浅色踩实斑、手绘起伏边）、青石板路（窄条石错缝、深色路缘）、官道（宽大条石 + 9 px 宽路缘石 + 金线）。分界线只落在 x=24 / y=24，经过边中点且垂直于边；单角是凸 1/4 圆，三角是凹缺口，1001 / 0110 画成两块不相连的角。纹理按 48 周期环绕，同一种子，任何瓦片接起来是同一张铺装。
- 城墙：`east-common-wall-<mask>`，16 张，facility=city_wall。夯土包砖，墙体比逻辑格四边各收 6 px，墙高 26，向上伸 30 px；南沿与东西沿是灰瓦压顶垛口（开望孔），北沿是女墙；砖缝 x 周期 8、海墁周期 12/6，全按世界坐标。
- 叠加件（按逻辑格放，锚点 = 逻辑格前沿中点）：
  - `east-common-wall-gate-h`：3×1，东西向墙段城门楼，中格石券门洞 + 城门匾，墙顶重檐歇山城楼（7 间 + 腰檐 + 5 间平座），facility=gate
  - `east-common-wall-gate-v`：1×1，南北向墙段城门楼，二层悬山山面朝南，facility=gate
  - `east-common-wall-tower`：1×1 角楼，重檐攒尖 + 宝顶，facility=watchtower
  - `east-common-wall-tower-xieshan`：1×1 角楼，重檐歇山 + 鸱吻，facility=watchtower

## 已知问题

- gate-v 的门洞是东西向穿墙，斜俯视下看不到，只能靠城楼和匾认出这是门（gate-h 的门洞朝南，看得见）。
- 叠加件在预览里的排序键是「逻辑格前沿 + 24.5」，好压住同一行的墙瓦片；正式接入时排序规则要按这个来，否则会被墙瓦片盖住。
- 土楼占地是满 2×2，四周不留空地，紧挨别的建筑时会显得太挤。
- 民居没有按 FacilityKind 分配（规范要求民居 facility=null）；城墙、城门、角楼以外的 FacilityKind 归 east-special。
