# 地图迷雾美术素材（已定稿保存，尚未接入游戏）

两套迷雾风格的原创程序化 SVG 素材与离线预览页。全部是手写路径，没有使用任何参考图的像素。
目前只保存素材，不改 `app/static/map-fog.js`、`play-ui.js`、`app/fog_art.py` 等正式代码；
等地图系统（其他智能体负责）完成后再统一接入。

## 接入约定（用户已确认）

- **风格由玩家在设置里手动选择**：西方中世纪 / 东方玄幻，不按世界观自动切换。
- **安全边界不变**：未知区的地形由服务端 `fog_art.py` 填常量色，不下发给客户端；这里的素材只负责装饰，
  接入时未知区必须完全不透明，透明处不能超出服务端给出的可见边界（见 `tests/test_fog_alpha.py` 的约束）。
- 预览页里的底图、"示意地点"、左下角说明标签都只是示意，接入时不带。

## 文件

| 文件 | 内容 |
|---|---|
| `fog-brushes.js` | 西方卷云笔刷：6 枚手工形状（扇贝长带、大云岸、双层卷云、斜卷浪头、小簇云、低平云脚）+ 5 档羊皮纸→暖灰褐色板，`render()` / `standalone()` 输出 SVG |
| `export-svg.js` | `node app/static/map-art/fog-brushes/export-svg.js` 导出 12 个 `brush-<id>-<key>-{mid,light}.svg` |
| `fog-xiangyun.js` | 东方祥云：`cluster()`（馒头云 / 高耸主角云 / 长云带 / 小簇云，金线勾边、叠晕、卷纹）、`waves()` 海水纹（含卷浪头）、`fuchuan()` 福船、`cloudlet()`、`PAL` 色板 |
| `fog-celestial.js` | 角饰与船：东方 `redSun()` 红日、`eastMoon()` 新月；西方 `westSun()` 木刻人面太阳、`westMoon()` 人面月牙、`westStar()`、`westWaves()` 雕版海浪；船型 `carrack()` 卡拉克船（雾效使用）、`cog()` 柯克船、`galleon()` 战列舰（后两种仅作参考） |
| `preview.html/css/js` | 离线预览（file:// 直接打开）：笔刷图册、西方直段/弯段/围合、西方船型参考、东方弯段/围合 |

浏览器里分别挂到 `window.FogBrushes`、`window.FogXiangyun`、`window.FogCelestial`；Node 里 `module.exports`。
所有随机都由种子派生（mulberry32），同一种子画出来完全一样。

## 两套风格的画法

**西方中世纪**：云一律不透明平涂 + 墨线，一排排平行于探索边界像屋瓦一样叠放，越往外云团越大、颜色越深（浅羊皮纸 → 灰褐），
外层云体内有鱼鳞状叠层线；铺满到画面边缘，内缘少量小簇云伸进地图。右上人面太阳、左上人面月牙配八芒星，日月下半身被云遮住。
底部雕版海浪：浪高沿岸起伏，偶尔卷起沉在水里的大浪头；每排一到两艘卡拉克船（远小近大，船与船左右错开）。

**东方玄幻**：国潮祥云，圆云头合成一团、整团金线勾边，团内两到三圈叠晕、大云头里勾金色卷纹；
颜色内缘米白、赭黄，往外混入橘红、朱红、青绿，最外赭褐、藏青；大小云团混排，偶尔一团高耸的主角云。
右上红日、左上新月；底部彩色海水纹（金线、三道平行水纹、卷浪头）与福船。
