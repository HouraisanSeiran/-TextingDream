# 天色天气叠层 `WeatherFX_sky`（docs/weather-spec.md 第 8 节）

负责霾 `haze`、浮尘 `dust`、扬沙 `blowing_sand`、热浪 `heatwave`、太阳雨 `sunshower` 和彩虹。尚未接入游戏，只有素材和预览页。

## 文件
| 文件 | 内容 |
|---|---|
| `sky.js` | 叠层模块，挂 `window.WeatherFX_sky` |
| `preview.html` / `preview.js` | 独立预览页：城镇底图 + `WeatherFX_daylight` 调色 + 本模块 |
| `preview-town.js` | 底图：`layout-samples.js` + `town-render.js`，做法照 `weather-fx/index.js`，挂 `window.SkyTown` |

## 接口（同 3.1）
```js
var sky = WeatherFX_sky.create({ seed, noise: window.WeatherNoise });
sky.resize(1400, 900, dpr);
sky.setScene(scene);          // 用 ground（道路）、water、buildings、occluder（可选）
sky.update(state, dt);
sky.draw(ctx, pass);          // ground / precip / fog / light / bow，其余 pass 直接返回
sky.dispose();
```
- 读的字段：`kind`、`intensity`、`aerosol {type, density}`、`rainbow`、`heat`、`ground.dust_cover`、`cloud_cover`、`wind`、`time.hour / sunrise / sunset`。
- **对任何 kind 都生效**：`aerosol`、`rainbow`、`heat` 有值就画（例如 `clear` + `heat`、`rain` 刚停 + `rainbow`）。字段缺省时按 kind 回落：`haze/dust/blowing_sand` 用 `intensity` 当对应气溶胶密度，`heatwave` 用 `intensity` 当 `heat`，`sunshower` 用 `0.8×intensity` 当 `rainbow`；`dust_cover` 缺省时浮尘、扬沙按强度给一个值。
- `aerosol.type = 'sand'` 且 `kind = 'sandstorm'` 时不画：沙暴尘幕归 `snow/sand.js`，避免叠两层。
- 所有目标量都以约 0.4 s 的时间常数平滑过渡，切换天气时不会跳变。
- 坐标一律用 CSS 像素，draw 内部自己 `setTransform(dpr)`，出口恢复 ctx 状态。
- **热浪需要回读底图**：fog pass 从 `ctx.canvas` 取像素做折射，所以调用方必须在 fog pass 之前把城镇画进同一张 canvas（总预览页和本预览页都是这样画的）。

## 各 pass 做法
| pass | 内容 |
|---|---|
| `ground` | 积灰：域扭曲 fbm 场（1/4 缩小，只按画幅烘一次），阈值随 `dust_cover` 下降；道路格阈值抬高、积得少，建筑剪影和水面不积。只有覆盖率变了才重新写 ImageData。太阳雨时在道路格上闪烁暖色亮斑（`lighter`）。 |
| `precip` | 扬沙流沙带：1/4 缓冲里沿风向旋转铺拉长的流沙纹，再乘三档阈值的断续遮罩（零星 → 成带 → 连片），抠掉建筑剪影，让沙从房子底下流过。沙粒是斜飘短线，分两层颜色，一层一次 stroke。浮尘细粒按深度分三批 rect。太阳雨雨丝是短的暖金色亮线（`lighter`），带落地小溅环。 |
| `fog` | ① 热浪：画布降到 1/2 → 每 2 行一条横向条带按噪波错位（越往画面上方越远，位移越大），强档再叠一层反向半透明拖影 → 分三条竖带做列位移（热气上升的抖动）→ 强档把远景压成 22×6 粗缓冲再平滑放大，做出「融成色带」→ 用「竖向渐变 ∪ 上行噪波热气团」遮罩贴回。最后做 saturation 去饱和，加上浓下淡的白色 screen。② 气溶胶：saturation 去饱和 → multiply 压色 →（尘、沙）soft-light 染黄 → 1/6 缓冲里两层平铺霾团反向错动，乘竖向渐变 → 上浓下淡的远近幕。浮尘再加一层暖白 screen，让天色更亮。 |
| `light` | 太阳雨：soft-light 暖金调色，加几道向阳一侧的斜光束（`lighter`），不压暗画面。 |
| `bow` | 彩虹：1/3 缓冲里用径向渐变画七色带，边缘 alpha 呈钟形。主虹内侧天色略亮。`rainbow > 0.62` 起渐显副虹：半径 ×1.27、色序反、更淡。平铺云纹 `destination-out` 把弧带局部遮淡，弱档挖得多。虹脚向下淡出，最后用 screen 叠上。 |

彩虹位置：太阳方位用 `theta`（与 `daylight.js` 的 `sunOf` 一致，0 = 日出在东 / 画面右，π = 日落在西 / 画面左），虹心放在背阳一侧（`cx = W/2 − cos(theta)·0.28W`）。太阳低时虹大、弧顶贴近画面上沿；太阳高时虹缩小下沉并变淡。只在 `sunrise ≤ hour ≤ sunset` 时画。

噪波：全部来自 `WeatherNoise`。平铺纹理用 `tile()` 预烘（128²：霾团、流沙纹、断续遮罩 ×3、云纹、热气团），积灰场用 `warp2`。每帧只有热浪的条带位移和少量粒子摆动调用 `noise2`（每帧几百次），没有逐像素噪波。

## 三档效果
（截图见 `artifacts/weather/sky-*.png`）

| 天气 | 0.0–0.3 | 0.3–0.7 | 0.7–1.0 |
|---|---|---|---|
| 霾 haze | 远景（画面上部）发灰黄，近处几乎不变 | 整体压色去饱和，上半幅灰幕明显，霾团缓慢流动 | 浓霾：上部只剩轮廓，近处也发灰 |
| 浮尘 dust | 天色微黄，零星细尘 | 天色昏黄偏亮，细尘可见，地面成片积灰（道路少） | 浓尘灰黄，能见度低，积灰连片 |
| 扬沙 blowing_sand | 尘幕很薄，地面零星流沙线，少量斜飘沙粒 | 贴地流沙成带，沙粒加密，城镇仍清晰 | 流沙连片、沙粒密集，尘幕仍比 sand.js 沙暴薄 |
| 热浪 heat | 远景轻微横向抖动 | 条带错位 + 竖向抖动明显，天色发白 | 强烈扭曲，远景融成横向色带，整体发白去饱和 |
| 太阳雨 / 彩虹 | 稀疏亮雨丝；彩虹淡，被云纹挖成几段 | 金色雨丝 + 地面亮斑；完整主虹弧 | rainbow > 0.62 起渐显副虹（外侧、色序反、更淡） |

上表是按参数设计的预期效果，截图未能目视确认（见「已知问题」）。代替目视做了像素统计：每张截图与同城镇同时刻的 clear 基线比，画面分上 / 中 / 下三段（脚本在会话临时目录 sky-stats.mjs）。「细节」指相邻像素亮度差相对基线的比值，1 = 与晴天一样清楚。

| 截图 | 上段 Δ / 细节 | 下段 Δ / 细节 | 上段饱和度 |
|---|---|---|---|
| 霾 0.2 / 0.5 / 0.9 | 11 / 0.76 → 28 / 0.45 → 40 / 0.16 | 6 / 0.91 → 18 / 0.73 → 28 / 0.49 | 0.25 → 0.19 → 0.16 |
| 浮尘 0.2 / 0.5 / 0.9 | 12 / 0.82 → 26 / 0.56 → 36 / 0.32 | 6 / 0.91 → 18 / 0.73 → 25 / 0.54 | 亮度 139 → 143 → 153（变亮） |
| 扬沙 0.2 / 0.5 / 0.9 | 7 / 0.89 → 18 / 0.68 → 28 / 0.46 | 4 / 0.94 → 15 / 0.81 → 21 / 0.61 | 0.35 → 0.38 → 0.40（偏黄不变灰） |
| 热浪 0.2 / 0.5 / 0.9 | 18 / 0.60 → 30 / 0.43 → 46 / 0.19 | 8 / 0.86 → 12 / 0.76 → 18 / 0.70 | 0.22 → 0.16 → 0.11，亮度 145 → 171 |

三档都单调递增，上段（远处）一律比下段变化大。霾去饱和、发暗；浮尘变亮；扬沙保持饱和、细节保留最多（城镇可辨）；热浪发白、去饱和。太阳雨下段亮度 153（地面亮斑、暖光），不压暗。单虹截图整段平均 Δ 只有 10（虹带占画面小，平均值说明不了它好不好看），双虹 Δ 25。

## 性能（Playwright + 本机 Edge，1400×900，重负载档，每项采样 3 s）
| 场景 | dpr=1 fps（min） | dpr=2 fps（min） | 本模块每帧耗时（含 daylight） |
|---|---|---|---|
| 扬沙 0.9 | 116.8（107.8） | 32.7（30.0） | 1.5 ms |
| 热浪 0.9 | 119.8（119.8） | 65.2（35.9） | 3.4–5.7 ms |
| 太阳雨 0.95 | 119.8（119.8） | 39.0（36.7） | 1.8 ms |
| 霾 0.9 | 119.8（119.8） | 49.0（35.9） | 1.0 ms |
| 浮尘 0.9 | 119.8（119.8） | 43.5（41.9） | 1.2 ms |

表中是 16:53 那一轮。17:08 加了「气溶胶抬云量」后又跑了一轮，整机明显变慢（dpr=1 各项都只有 72–76 fps），这一轮扬沙 0.9 在 dpr=2 下只有 29.3（min 25.9），**低于 30 fps 目标**，其余各项仍不低于 30。各轮之间波动较大。dpr=1 下 fps 被 120 Hz 刷新率封顶。dpr=2 时 JS 耗时不到 6 ms，fps 主要受全屏合成（底图两张 2× 栅格 + daylight 的 multiply / soft-light）限制。扬沙 0.9 的最低帧接近 30 fps 下限。

## 预览页
`http://127.0.0.1:8765/app/static/weather-fx/sky/preview.html?kind=haze&intensity=0.5&dpr=1&town=city/west/common/1`
- 控件：城镇样例、kind、强度、aerosol 类型与密度、heat、rainbow、积灰、云量、风向 / 风速 / 阵风、时刻、联动、daylight 调色开关、暂停 / 单步。
- 「联动」勾选时，切天气或拖强度会自动设出自洽的气溶胶、heat、rainbow、积灰和风。要单独试叠加（例如 clear + heat、rain + rainbow），取消联动后自己拖。
- daylight 收到的是代理状态：新 kind 换成 `clear`（预览里的 rain 换成 `cloudy`，表示雨刚停）。有气溶胶时把云量抬到约 0.95×密度，让建筑投影变淡。
- 调试接口 `window.__sky`：`set(o)`、`state()`、`fps()`、`work()`、`resetFps()`、`ready`。
- 布局样例里只有 west / east 两种风格，没有阿拉伯风格，所以扬沙、浮尘默认用 `town/west/common/7`。

## 已知问题
- **截图未能目视确认**：当前模型读不了图，15 张截图只做了像素统计（见交回报告），没有人眼看过。
- 热浪折射回读 `ctx.canvas`，所以必须在同一张 canvas 上、fog pass 之前画好底图。总预览页如果分层画到别的 canvas，就没有折射，只剩发白和去饱和。
- 气溶胶是全屏均匀的远近渐变，没有用 scene 区分屋顶和地面。高建筑的屋顶不会比地面更清楚。
- 彩虹位置是写意的：俯视画面里放在背阳一侧、画面上方。正午太阳高时虹缩小变淡，没有严格按 42° 的几何计算。
- 扬沙 0.9 在 dpr=2 下最低帧约 30 fps，再加别的模块可能跌破。可以考虑减少 `MAX_GRAIN`，或把流沙缓冲降到 1/6。
