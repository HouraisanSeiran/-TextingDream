规范：`docs/weather-spec.md` 第 1 节（状态）、3.1–3.5 节（叠层接口 / scene / pass / 24h 景色）、第 5 节（极光）、第 6 节（测试方式）。

## 用法

```js
var layer = WeatherFX_daylight.create({ seed, noise: window.WeatherNoise });
layer.resize(1400, 900, dpr);
layer.setScene(scene);          // 3.2 节 scene；可选 scene.objectsImage / objectsScale（见下）
layer.update(state, dt);        // state = 第 1 节天气状态（+ 可选 aurora{strength,hue}）
// 每帧：底图(地面+水) → draw('reflect') → 建筑/树 → draw('light')
layer.draw(ctx, 'reflect'); layer.draw(ctx, 'light');
layer.setDisturb(0..1);         // 给雨效的接口：额外打碎倒影
layer.sky();                    // 当前天色/暗度参数，给其他模块参考
layer.dispose();
```

- 坐标一律 CSS 像素，`draw` 内部自己 `setTransform(dpr)`。
- `light` 用 multiply / saturation / soft-light / lighter，对已画好的底图起作用，所以必须最后画（`flash` 之前）。
- `reflect` 要画在建筑之下：倒影画进水面，岸上实物再盖上去，水边屋檐不会被倒影盖住。
- `scene.objectsImage`：只含建筑/树/摆件的透明底画布（像素 = CSS × `objectsScale`）。给了它，水里就是岸上实物的真实镜像；不给则退化为暗色剪影。
- `scene.buildings[i]` 可带 `depth`（底面进深像素，用于投影）、`tree`（树用椭圆影）。
- 灯亮度只由时刻决定（不靠累积），拖滑杆 / 截图结果可复现。

## 各 pass 要点

**light**（半分辨率光照图 → multiply，再调色）
- 时段乘色：12 个关键帧，按日出 / 日落偏移定位，`smoothstep` 连续插值；昼夜过短时按比例压缩关键帧间距，保持单调。
- 建筑投影：太阳时角决定方向（日出向西、日落向东），高度决定长度（cot，夹在 0.25–2.6 倍）。房子用底面矩形沿投影方向扫出的凸包，树用拉长椭圆；每栋在小缓冲里挖掉自身，不吃自己的影子；整张模糊一次；太阳变化一档才重画。另加背光面横向渐变，以及晨昏背向太阳一侧的斜向压暗。
- 云影：云纹理的暗色版放大 3 倍，随风平移，云量中等时最明显。
- 灯光照地：暖色光斑盖掉夜色（source-over 画进光照图）。
- 天气：阴雨（drizzle/rain/storm/sleet）去饱和 + 乘冷灰 + 压暗；雪提亮偏冷；沙暴乘黄褐 + 柔光黄褐；雾、阴天去饱和压灰。
- 辉光：窗 / 路灯 / 火三种预烘径向精灵，`lighter` 混合；火与灯焰用两层值噪波闪烁。
- 萤火：晴朗、非冬季的夜里，噪波驱动游走与明灭。
- 极光环境光：极光颜色的淡柔光 + 很弱的 lighter。

**reflect**（先合成到水面缓冲，再水波位移、遮罩贴回）
1. 天色：远岸映地平色，近处映天顶色；晨昏时太阳一侧加暖辉。
2. 星空：512² 平铺纹理，平铺 fbm 决定星星成团 / 留空；暗星底 + 三张亮星相位交叉淡入，即闪烁；随时刻平移（天球转动）。
3. 银河：384×128 预烘，带中心线用 fbm 弯曲，域扭曲 fbm（`warp2`）做星云，第二张扭曲噪波挖暗尘带，再加密集细星；绘制时放大旋转，随时刻缓慢转动。
4. 极光：见下。
5. 云：256² 平铺域扭曲 fbm 密度（只算一次），按云量重映射阈值；白天亮、夜里暗，夜里会盖掉星星。
6. 月亮：64² 月面（`warp2` 月海 + 值噪波麻点 + 临边昏暗），按 `moon_phase` 裁出盈亏（渐盈亮右、渐亏亮左，暗面留地照）；新月正午上中天、满月午夜上中天，按时角横移、按高度纵移，白天很淡。
7. 岸上倒影：镜像底稿以各建筑底边为轴翻转，场景变化时烘一次。
8. 灯光倒影：竖向拉长的光柱，下方再加噪波决定亮灭的断续短横（碎影）。
9. 水波：每 2–3px 一条横带，按两层值噪波 + 正弦横向位移；`disturb`（雨 / 风 / `setDisturb`）越大越抖越碎。星空、月亮、极光、倒影都吃同一套位移。
10. 闪光：平铺短横亮线纹理，月光 / 日光方向一道闪光带，全水面再加细碎闪光。

**极光**（`state.aurora{strength,hue}`；`kind='aurora'` 且没给 aurora 时用 `intensity`）
- 只在夜里画（随天黑程度渐显）；云量 > 0.35 开始被遮，降水 / 雪 / 沙暴 / 雾大幅压低。
- 色相：0 绿 → 0.5 青紫 → 1 品红。
- 帘幕纹理 256×128 横向可平铺：平铺 fbm 两行，一行定射线亮度、一行定射线长度；亮边贴远岸（倒影里远岸就是地平线），往近处渐淡。
- 三档：< 0.3 远岸一道淡绿光弧；0.3–0.7 加帘幕，6px 竖条贴图，低频 fbm 决定每条的纵向位置与取样横移（褶皱扭动），随时间漂移，值噪波做明暗脉动；> 0.7 三层多色帘幕铺满水面。
- 窄水面（主水块高 < 120px，例如港口样例只有一行水格）：帘幕尺度固定 170px、亮边贴远岸，先铺一层淡极光色底，摆幅减半，超出水面的部分被遮罩裁掉；光弧下沿放在水面上 1/3 处。
- 同在倒影缓冲里，所以和星空一样被水波打散。
- 光照 pass 另有极光环境光（淡柔光 + 很弱的 lighter），强档时岸上屋顶也微微偏绿。

## 性能

预烘：星空 512² × 4、银河 384×128、云 256²、闪光 256²、月面 64²、极光 256×128（色相 / 档位变化才重烘）、投影图（太阳变化一档才重画）。每帧只做 drawImage 平移放大、约 300 条水波横带、几十个灯精灵和全屏混合，没有逐像素噪波计算。

## 自检

- `node --check` 全部 JS 退出码 0。
- 截图脚本（Playwright + 本机 Edge，1400×900）：港口西式样例 05:30 / 12:00 / 18:30 / 22:00、23:00 极光 0.2 / 0.5 / 0.9、23:00 极光 0.9 + 云量 0.9；产物 `artifacts/weather/daylight-*-v5.png`（另有 `-dpr2-v5` 两张）。pageerror / console error 为 0。
- fps：dpr 1 与 dpr 2 都在 119.8（截图机显示器刷新上限）；每帧 JS 工作量 dpr 1 约 0.9–3.1 ms，dpr 2 约 3.0–3.9 ms（极光 0.9 最重）。

## 修过的问题（v4 → v5）

- 城墙按格给包围盒，逐格投影在城墙内外留一圈方块暗斑：投影跳过 `wall:true`。
- `mainPool` 按 0 原点切格，预览裁窗偏移不是格宽整数倍时包围盒错半格、多出一行：改为按第一块水格的余数对齐。月亮、光弧、帘幕因此落回真实水面。
- 港口水道只有一格高，极光三档差别看不出来：光弧加亮下移，窄水面帘幕改固定尺度贴远岸。
- 预览页 `/favicon.ico` 404：加 `<link rel="icon" href="data:,">`。

## 已知问题

- 港口样例的水面只有一行 9 格（约 48px 高），星空、银河、极光帘幕都只能露出一条窄带；要看大面积倒影用「自拼河镇」。
- 极光 0.2 档在港口窄水道里只是一层很淡的绿，和晴夜差别要细看；0.5 / 0.9 差别明显。
- 18:30（日落 18:24 后几分钟）亮灯已偏多，比表里「少量」多，阈值随机分布偏低。
- 本模块只实现 `reflect`、`light` 两个 pass，`ground` / `precip` / `fog` / `flash` 调用时不画任何东西；湿地、积雪由雨雪模块负责。
- 倒影只取紧邻水边（底边距水面 −12 ~ +60px）的建筑；离岸远的高塔不进倒影。
- 极光只出现在倒影里，画面不含天空，岸上只有环境光染色。
