## 2. 视觉改了什么

- **色板**：单色灰 → 中性深色底（`#1a1b1d` / 卡 `#232529` / 线 `#33363b`）+ **一个**青绿强调 `#6fbf9f`。
  强调只用于：主按钮、取样、选中指示条、eyebrow、成功态。**不是满屏青绿。**
- **圆角一律 ≤ 8px**（`--r:8px`），不再有 13/14/18/20px 混用。
- **字号**：正文 14.5px/1.65；辅助标签 ≥ 11px（此前的 9.5/10.5px 已回退）。手机 390 专属优化**本轮暂停**（见 §6）。
- **侧栏**：三组（工作空间 / 地图与世界 / 创作与调试），选中项 2px 强调条 + 提亮 + 小标签变色。
- **页头**：102px → 72px 并 sticky。
- **输入区**：去掉 `position:sticky`（原来会压住历史与按钮），回到正常文档流，底部留 `env(safe-area-inset-bottom)`。
- **地图工具**：主图区只有一条细边（不再"卡片的卡片"）；右栏一整块 + 分隔线分组；
  图层是**分段选择器**（一条外框 + 分隔线，不是一排独立胶囊）；读数为键左值右、数值等宽对齐。
- **错误/警告不只靠颜色**：错误前置「！」，成功前置「✓」，并提高色阶对比。

## 4. 本轮修掉的两个真 bug（由美化暴露）

1. **导航 `insertBefore` 抛 `NotFoundError`**：把导航拆成多个 `<nav>` 后，`towns.js` /
   `element-assembly.js` / `map-import.js` 仍在往「traces 按钮所在的那个 nav」里插。
   已改为「追加到『地图与世界』那组末尾」，不再假设某页在哪个 `<nav>` 里。
2. **导航重复**：`世界地图工具` 同时写在 `index.html` 与 JS 动态插入里，出现两条。已只保留 JS 那一份。
