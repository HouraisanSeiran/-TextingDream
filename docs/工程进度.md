## 一句话

文字驱动的开放世界探索游戏：玩家用文字在持久世界上行动，规则先结算，模型只叙述。工程名（织梦 / TextingDream）后续可能更换。

当前实现仍偏短篇事件链；世界生成、城镇布局、天气画面和经营大多停在作者工具，还没有收成同一条开放世界旅程。

2026-11-12 已明确 [故事包的新目标定义](story-package-definition.md)：整合地理、数据库设定、世界历史及大陆与王国背景；独立城镇生成处于其下一级，补充具体聚落和道路。目前已更新定义与入口文档，现有生成器仍有城市及事件编译耦合，尚未完成代码和数据格式改造。

## 玩家旅程

| 状态 | 内容 |
|---|---|
| 已接通 | 回合（`Service.turn` → `Runtime.prepare_turn` → 叙述 → `finish_turn`）、无事件本地行动、移动 / 等待 / 关闭 / 回滚 |
| 已接通 | 奖励、交易、压力、检定 v2（故事包开启对应 `mechanics` 后） |
| 半接通 | 任务：有玩家投影和变化通知；接受 / 放弃 / 提交 / 过期未进行动结算与时间推进 |
| 半接通 | 事件池：包声明 `mechanics.events` 后随压力推进 |
| 已接通 | 玩家地图默认支持 `world_map_product`，保留 opt-in civ-atlas，仍经原 play-map 服务端掩膜/迷雾；本次作者登记链不迁玩家默认或存档。天气只读 `GET /api/sessions/{id}/weather`（不写档、不推进时间），未自动改读本批月气候 |
| 未验收 | 在线模型叙述质量、单局时长、真人试玩 |

当前可对照的短篇包在 `StoryPackage/world_short_tavern`。启用哪个包由里层指针决定。
