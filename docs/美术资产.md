# 美术资产

盘点日期：2026-11-10。symbol 数由当天读取 `app/static/` 里的 `<symbol id>` 与各目录 `meta.json` 得到。绘制模型按作者说明为 Claude Opus 5.5。

本文只登记现有画面资产、放在哪、现在接到哪。画法细则仍以 [town-art-spec.md](town-art-spec.md)、[map-fog-art.md](map-fog-art.md)、[weather-spec.md](weather-spec.md) 为准。玩家旅程接到哪，以 [工程进度.md](工程进度.md) 为准。2026-11-05 的旧盘点在 [archive/root/美术资产交接_2026-11-05.md](archive/root/美术资产交接_2026-11-05.md)。

素材是本工程原创程序化图形：SVG 用 `<symbol>` 和固定 viewBox，天气与骰子用 Canvas。不引用外部图片、字体或脚本。

## 画风

三套可并列的平面风格，色板在迷雾脚本和 [town-art-spec.md](town-art-spec.md) 里对齐：

| 风格 | 画法 | 主要文件 |
|---|---|---|
| 西式奇幻 | 木刻墨线 `#4a3826` + 羊皮纸淡彩，平涂，不用渐变和模糊 | `fog-brushes.js`、`fog-celestial.js`、`west-*` |
| 东方玄幻 | 国潮平涂 + 金线勾边，色板与 `fog-xiangyun.js` 的 `PAL` 一致 | `east-*` |
| 阿拉伯 | 城镇目录独立成套；资源点与城防目前回落西式或东方 | `arab-base`、`arab-special` |

大地图另有三档渲染风格，记在 `app/static/map-art/styles.json`，由 `app/map_render.py` 读取：`simple`（分层设色 + `map-art.svg` 地形符号）、`medieval`（西式手绘，只用 `map-art-medieval.svg`）、`eastern`（东方古舆图，只用 `map-art-eastern.svg`）。后两档不叠地形符号，也不画高程点。

城镇内部是另一套视角：3/4 斜俯视、48 px 正方形网格、光从左上、锚点为占地前沿中点。规范见 [town-art-spec.md](town-art-spec.md)。

## 天气叠层

目录 `app/static/weather-fx/`。总预览 `index.html`。每个模块提供 `create`、`resize`、`setScene`、`update`、`draw`、`dispose`，绘制顺序为 `ground → reflect → precip → fog → light → bow → aurora → flash`。规范见 [weather-spec.md](weather-spec.md)，生成字段见 [weather.md](weather.md)。

| 模块 | 全局对象 | 画面 |
|---|---|---|
| `rain/rain.js` | `WeatherFX_rain` | 毛毛雨、雨、雷暴、冰雹，以及雨夹雪里的雨 |
| `snow/snow.js` | `WeatherFX_snow` | 雪、暴风雪、雨夹雪里的雪 |
| `snow/fog.js` | `WeatherFX_fog` | 雾 |
| `snow/sand.js` | `WeatherFX_sand` | 沙暴 |
| `daylight/daylight.js` | `WeatherFX_daylight` | 昼夜调色、灯光、星月与极光的水面倒影 |
| `aurora/aurora.js` | `WeatherFX_aurora` | 写意极光帘幕 |
| `ice/ice.js` | `WeatherFX_ice` | 冻雨、霰、霜、雾凇 |
| `wind/wind.js` | `WeatherFX_wind` | 台风、龙卷风；雨由 rain 组合 |
| `sky/sky.js` | `WeatherFX_sky` | 霾、浮尘、扬沙、热浪、太阳雨、彩虹 |
| `fantasy/fantasy.js` 及四个 `fantasy-*.js` | `WeatherFX_fantasy` | 魔力风暴、灵雾、瘴气、灰烬雨 |

奇幻四种默认不进随机池，只在世界设定允许时出现。天气数据接口 `GET /api/sessions/{id}/weather` 已可只读查询；这些叠层还停在独立预览，没有画进主站或旅行结算。文件在、预览能开，不等于每种天气都已目视验收。

## 骰子

`app/static/dice.js` 提供 d20 的几何、斜视相机和 Canvas 绘制。三种材质：金属、木质、水晶。游戏内投骰走脚本化翻滚，停在服务端给出的面；自由物理只在 `dice-physics-demo.html`。演示页还有 `dice-demo.html`。首页已经加载 `dice.js`。d4、d6、d8、d10、d12 不在这套文件里。

## 界面皮肤

`app/static/theme.js` 在首页切换三套皮肤，选择记在浏览器 `localStorage`（键 `textiledream-ui-theme`），也可用 `?ui-theme=` 临时指定。

| id | 名称 | 样式 |
|---|---|---|
| `classic` | 森林手记 | 不加额外皮肤，沿用 `atelier.css` 的地图优先阅读层 |
| `retro` | 现代复古 | `retro.css` |
| `medieval` | 中世纪魔幻 | `retro.css` 的结构 + `medieval.css` 的橡木、金线、蜡封色 |

`style.css` 是底层的扁平工作台。`workbench.css`、`worldgen.css`、`town-plan.css`、`map-tools.css`、`narrative-workbench.css` 是作者工具的布局，不另立画风。

## 已知缺口

这些是目录和对照表上仍能直接看到的空档，不是新的美术方向：

- 阿拉伯没有独立的资源点、地面、棱堡目录。生成器会回落西式或东方，并在作者界面写明回落原因。
- 精灵、矮人、兽人有部分民居、城墙和工事；公共设施不全时回落人族。东方和阿拉伯的异族设施回通用套。
- 货币图标仍按便士 / 先令 / 镑绘制。
- 迷雾笔刷、天气叠层、物品与资料条目图标都还没有进玩家主界面。
- 部分资源地块的地面硬边、密集屋顶对后排的遮挡、跨风格屋面是否允许混用，仍要在城镇预览里以 150% 和 200% 目视确认。记录见 [archive/handoffs/town-art-review-2026-11-06.md](archive/handoffs/town-art-review-2026-11-06.md)。
