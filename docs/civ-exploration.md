# civ 城镇、道路与玩家移动

## 试玩入口

运行服务后，在左侧旅程中选择 **塞瓦雷拉：城镇与道路试玩**。

- **城镇街区**：点击相邻建筑或左侧目的地，确认后进入。先到集市，可以继续去旅店、工坊和议事厅。
- **世界道路**：从城镇入口选择另一座城镇或驿站，也可以点击地图上的相邻地点圆点。确认框会显示实际结算的小时数。
- 刷新页面后，从左侧重新选择该旅程，继续已保存的位置。首页仍沿用原来的作者模式，不自动选择存档。

自行生成时，打开左侧“世界地图”，在地图上方选择起点城镇，点击“生成城镇并探索”。每次建立独立旅程与固定的故事包版本；已有旅程不被重写。也可以先使用原有世界生成参数生成新的 civ 世界，再选择起点。

## 生成与结算

世界地形、城址、城名、道路和航线来自已登记的原生 civ 快照。上游 worker 原有的道路生成继续使用，宿主显示城镇、名称和路线；后端新增道路图编译，将上游 `Route.cells` 转换为真正可旅行的连接。

按开局年份过滤未建城、未来道路和已废弃道路；有历史地形分段时使用相应时代的道路集合。从起点沿路选择最近的最多8座可达城镇。路径经过另一城镇时必须先到该城，不把它静默跳过。当前示例生成8座城镇、48个城内地点和2处沿途驿站，共61条双向连接。

城际距离由道路实际地块经纬链累计。步行大路5公里/小时、小径3公里/小时、航线12公里/小时是游戏规则假设，非实测速度；混合路段按各段速度累计。超过168小时的长途在原有路径地块上拆成驿站，复用当前引擎单次推进上限。驿站是新增的游戏内容，不冒称 civ 原有城址。

城内按原件哈希与城市ID确定性生成公共布局：入口、集市、旅店、工坊、议事厅，以及港口码头／高地望台／水井广场。城内布局是示意图；它没有宣称来自世界网格的建筑尺度地形，也没有取代原有完整社会经济城镇生成器。

城内移动按现有整数小时规则以1小时“街区探索”结算，距离仅作布局参考。精确分钟移动、连续行走动画和途中遭遇尚未实现。

移动统一经过既有 `Runtime.move`：核对邻接、当前事件和旅行规则，推进时间，更新玩家位置及已探索地点，一次保存。新界面发送状态版本，过期确认不会重复结算。公共街区之外的隐藏地点继续按玩家可见性规则过滤。

玩家地图仍只读取自己的掩膜底图和公共路线，不请求作者原件。城内示意图只返回当前城镇的公共节点；世界路线只返回两端已知的路段。
