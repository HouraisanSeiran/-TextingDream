日期：2026-11-11。状态：**内容规范v0.1草案；建设范围已确认B+C**。用户确认世界构建与模拟、数值玩法都要，生活城镇、冒险装备、魔法修行、国家历史全部补充，并可扩展更多领域。其他智能体负责采集，本会话只提供列表；具体schema与规则数值仍待定。本文档不实施迁移，不改变候选审核状态。

## 一句话定义

**设定资料库保存织梦跨故事包复用的资料条目：说明一个事物或规则是什么、在什么条件下成立、能与什么组合、会带来什么后果。每条资料保留来源和版本，供作者选择世界采用的内容。**

旧称“元素数据库”，单条内容旧称“元素”；界面与新文档统一写“设定资料库”和“资料条目”。现有 `element` 字段、接口及本目录路径保留兼容。

资料条目可描述事物、制度或世界规则；库内内容需要按任务选用，其中的规则候选由引擎明确接入后才可执行。

例如：小麦、钢铁、磨坊、铁匠职业、行会制度、巨龙、奥术施法、封建王国均可成为资料条目。某世界的“黑石磨坊”、某个铁匠、某城库存的三袋小麦属于实例，不属于通用模板。

## 已确认的建设方向

同时建设**世界构建与模拟（B）+数值玩法（C）**，所有领域均列入补充范围。采集既要完整定义和因果关系，也要各类适用的数值、动作与规则候选；不要求制度、姓名等无关条目硬填物品重量或攻击值。数值采集与引擎实现分开，候选规则不自动生效。

优先补：定义边界、来源支撑、结构化关系、生产与使用条件、地图适用条件、代价和失效情形。具体库存、价格波动、人口与势力状态留在世界/旅程层。
