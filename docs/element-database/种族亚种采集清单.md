# 种族亚种名称清单

日期：2026-11-13。对应[全领域采集总清单](collection-master-list.md)专题 36。用途：供负责人分派后续采集；本轮只补名称，不补能力、数值或完整资料，不写入数据库。

以下是待采集的名称范围，按来源体系分组；不是织梦已经采用的亚种，也不是某一版本的完整官方目录。“亚种”在这里作为检索用词，正式采集时再按原作区分亚种、血统、祖源和文化群体。表中的书名与版本是后续核对目标，本轮未逐项查阅原书。

## 3. 与现有资料的对应

- 精灵、矮人和西方巨龙分别先查 [western.json](../element-catalog/western.json) 中的 `western_elf`、`western_dwarf`、`western_dragon`。侏儒与哥布林目前共用概述 `western_gnome_goblin`，采集时分别识别。
- 巨人、兽人他称、东方龙、天狗及狐类先查 [fantasy-races.json](../element-catalog/fantasy-races.json)。本清单没有替这些神话母题确认统一的亚种树。
- [races-supplement.json](../element-catalog/races-supplement.json) 的六个原创族群暂不虚构亚种。人类文化、国籍、职业，以及狼人和吸血鬼的获得状态，也不直接按生物亚种收录。
- [D&D 对照缺口任务](collections/dnd-gap-task.md)中的四个可玩模板范围保留；本表用于另行分派亚种资料采集，不自动扩大该任务。本轮新增专有名称是查找原作资料的目标，不自动写入现有通用母题目录或成为本世界设定。

领取和交付方式沿用[资料采集交接](agent-handoff.md)。名称确定后，由采集方核对具体作品、版本、别名与所属关系。
