# 专题 02 采集记录：园艺与经济作物（第一刀，葡萄）

日期：2026-11-13。状态：候选，`needs_review` / `needs_detail`。不入库，不改 `produce.json`、故事包或引擎。

本刀只补已有元素 `produce/produce_grape` 的园地条件、修剪留芽、灌溉阶段和日本鲜食葡萄的采收窗口与产量。不重写定义，不新建同名条目。数字只来自本批读过的 FAO 正文，不用论文摘要。

## 已覆盖与未覆盖

已有、本批直接引用：`produce_grape`（鲜食、制干、酿酒三条用途；修剪可去掉当年生长量的 90–95%；冬季约 −7°C 可冻死植株或芽）。那些句子在旧条目里，本批没有重读其原始来源。

本批新写入的是日本鲜食葡萄生产章，以及 FAO 调亏灌溉章里对葡萄缺水阶段的说明。

未覆盖：苹果及其他果树、香料、糖、茶咖、棉、果园与温室的通用参数、加工率、铜币价格、欧洲酿酒葡萄的标准单产。日本章里的 12–24 t/ha 是现代鲜食品种的产量，不能当成酒庄或历史果园的收成。

## 边界

葡萄仍是 `produce_grape`。鲜食、酿酒、制干不另建 ID。

日本章的园地条件是当地选址：坡度小于 5 度、地下水位低于 1 米、年均降水约 1000 mm，且采收季降水宜少。这不是全球葡萄的气候门槛。旧条目已写冬季约 −7°C 的冻害，与「年均 1000 mm」不是同一套条件，两条并存。

短梢修剪留 2–3 芽是日本西部的一种剪法；东部用长梢。不能写成所有葡萄都留两三个芽。

灌溉：萌芽前和浆果膨大期需水最多；成熟期限制供水以提高品质。黏土果园夏季一次约 30 mm。这是日本鲜食栽培的做法。调亏灌溉章写的是另一套：坐果前不宜缺水；坐果后到转色前控水可抑制新梢；转色后仍要避免旱到影响健康和产量。两章都没有给出全球统一的毫米定额，本批不合成一个「葡萄需水量」。

除草剂名称出现在日本章，本批不收录用法。
