## 五、安全红线逐项落实（逐条可查）

### 5.2 不写剂量 / 配伍 / 煎法 / 服法 / 疗程 / 适应症

- 建库脚本内置禁用词检查（剂量、用量、服用、煎服、水煎、冲服、频次、疗程、适量、减毒、去毒、解毒、解救……）：
  **按句拆分，含否定词的句子（即免责声明本身）自动跳过**，其余命中也均为零。
- 全文无「每日 N 克」「一剂」「n 次」这类可执行的用量结构；引到的所有「克 / 毫米 / 厘米」均发生在描述**器官尺寸、果实直径、纤维长度、含油百分比**这类形态与成分层面。
- 涉及工艺的句子一律写成「存在这道工序」而不给参数，例如：厚朴的「发汗」、菊花的硫熏、栀子的蒸与漫、丁香的蒸。

### 5.4 罂粟壳：管制与成瘾性（写清，不写用法）

- **含吗啡、可待因、罂粟碱等多种生物碱**；生物碱分中枢作用（镇痛、麻醉、**成瘾性**）与平滑肌作用两类。
- **现代管制**：《中华人民共和国禁毒法》（2008-06-01 施行）第十九条禁止非法种植罂粟等毒品原植物、并禁止走私或非法买卖运输携带持有未经灭活的种子与幼苗；第二条将鸦片、海洛因、吗啡列为毒品。故罂粟壳**不具备食材、调料或家庭药材的任何地位**。
