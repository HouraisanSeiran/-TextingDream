# 世界设定：类型配比、科技 / 魔法档位与国家 / 种族 / 势力

故事包的 `worldview.setting` 记录一个世界「是什么样的世界」，元素库按它推荐候选元素。
设定只约束**推荐与提示**，不是引擎硬规则：作者仍可手动采纳任何元素，越档时只给冲突提示。

## 1. 类型配比 `genres`

列表，每项 `{tag, weight}`，`tag` 取元素库已有的 `genre:*` 值，`weight` 为 1–3（3 = 主体，1 = 点缀）。

| tag | 说明 |
|---|---|
| `western_fantasy` | 西幻 |
| `dark_fantasy` | 黑暗奇幻 |
| `eastern_fantasy` | 东方玄幻 |
| `xianxia` | 仙侠 |
| `steampunk` | 蒸汽朋克 |
| `historical` | 历史 |
| `real_world` | 现实 |
| `modern` | 近现代（止于二战前） |
| `folk_horror` | 民俗恐怖 |

例：西幻为主、带蒸汽机 → `[{tag:western_fantasy, weight:3}, {tag:steampunk, weight:1}]`。

## 2. 科技档位 `tech`（5 档，止于二战前）

| 值 | 名称 | 大致年代 | 典型可见事物 | 不应出现 |
|---|---|---|---|---|
| `classical` | 古典 | 青铜—古典铁器时代（约前 1200—公元 500） | 青铜/铁器、战车、帆桨船、水渠、石砌城邦、莎草纸与竹简 | 火药、印刷机、钟表 |
| `medieval` | 中世纪 | 约 500—1500 | 重犁与三圃制、水车风车、板甲与城堡、手抄本与早期雕版 | 火药火器、活字印刷机、远洋航海，更没有蒸汽机、铁路、电报 |
| `renaissance` | 文艺复兴 | 约 1500—1700 | 火绳枪与大炮、活字印刷机、远洋帆船与罗盘导航、机械钟、望远镜 | 蒸汽机、铁路、电报（仍靠人力、畜力、水力、风力） |
| `steam` | 蒸汽 | 约 1700—1880 | 蒸汽机、机械纺纱机、铁路、工厂、煤气灯、电报、后膛枪、铁甲舰、早期飞艇 | 内燃汽车普及、无线电广播、飞机 |
| `early_modern` | 近现代 | 约 1880—1939 | 电力电网、内燃机、汽车、电话与无线电、飞机、机枪、早期装甲车 | 核能、喷气机、雷达普及、电子计算机、二战及以后的技术 |

元素标签：`tech:classical` / `tech:medieval` / `tech:renaissance` / `tech:steam` / `tech:early_modern`，标的是**该元素最早能出现的档位**。
`tech:renaissance`（文艺复兴）是本次新增的标签，位于中世纪与蒸汽之间；元素库本身由另一份工作维护，这里只说明标签含义，尚未给任何元素补标。
档位顺序为 classical < medieval < renaissance < steam < early_modern，越档判断按这个顺序。

### 各档代表性科技（`markers`）

每档用 3 项「代表性科技的出现」来判定，`options()` 会随档位一起返回给前端：

| 档位 | 代表性科技 |
|---|---|
| 古典 | 铁器冶炼、拱券与水渠、帆桨船 |
| 中世纪 | 重犁与三圃制、水车与风车、板甲与城堡筑城 |
| 文艺复兴 | 火药火器（火绳枪）、活字印刷机、远洋帆船与罗盘导航 |
| 蒸汽 | 蒸汽机、机械纺纱机、铁路 |
| 近现代 | 电力与电网、内燃机、无线电 |

世界设定可选存 `tech_markers`（字符串列表，只能取自上表）。`world_setting.tier_from_markers(present)` 返回「该档及以下所有档的代表科技都已出现」的最高档，第一档都没凑齐则为 `None`。
它只用于判定与前端高亮，不强制使用：作者在世界设定卡片里勾选代表性科技后，页面会自动推断并高亮档位，也可以直接点选档位，**直接点选优先**，`tech` 字段以作者点选或保存的值为准。
档位高的世界可以包含低档元素（蒸汽世界里依然有长剑）；元素档位高于世界档位时视为越档。
没有 `tech:*` 标签的元素（草药、食物、种族等）对任何档位都不越档。

## 3. 魔法档位 `magic`（4 档）

| 值 | 名称 | 说明 | 适合的元素 |
|---|---|---|---|
| `none` | 无魔 | 世界中没有可验证的超自然力量；传说、迷信与宗教存在，但不产生实际效果 | 只接受无 `magic:*` 标签或 `magic:none` 的元素 |
| `rare` | 稀少 | 超自然力量真实存在但罕见、代价高或被隐藏，普通人一生可能只听说过 | 隐秘结社、禁忌仪式、单件遗物 |
| `common` | 常见 | 魔法是一门公开的行当：有学院、行会、法律管制，城镇里能找到施法者，但仍需专门训练 | 法师学院、魔药铺、护符市场 |
| `abundant` | 丰富 | 魔法渗入日常生活与基础设施：照明、交通、生产都可能依赖它，普通人也会用简单法术或魔法器具 | 魔导设施、浮空城、魔力能源 |

元素标签：`magic:none` / `magic:rare` / `magic:common` / `magic:abundant`，标的是**该元素要求世界至少达到的魔法档位**。
无 `magic:*` 标签视为不需要魔法。

## 4. 国家 / 种族 / 势力

`worldview.setting` 下三张短表 `polities` / `races` / `factions`，每项：

```json
{"id": "kingdom_ardel", "name": "阿尔德王国", "summary": "一句话说明",
 "tags": ["genre:western_fantasy", "tech:steam", "polity:monarchy"],
 "element_ref": null}
```

- 作者可以完全手写（`element_ref` 为空），并自由添加标签；
- 也可以引用元素库条目（`element_ref` = `namespace/element_id`），此时名称与说明可作为本世界的改写。
- 标签自由填写，推荐使用下面的前缀，方便推荐与检索：
  - 国家：`polity:monarchy` 君主国、`polity:empire` 帝国、`polity:republic` 共和国、`polity:city_state` 城邦、`polity:theocracy` 神权国、`polity:tribal` 部族联盟、`polity:merchant` 商业共和；
  - 通用：`genre:*`、`tech:*`、`magic:*`。

## 5. 元素库新增标签

- `kind:polity`：国家与政体模板（不是具体国家，作者据此改写成本世界的国家）。
- `tech:*` / `magic:*`：见上。
