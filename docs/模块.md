# 织梦模块说明

更新日期：2026-11-13。对应进度见 [工程进度.md](工程进度.md)，详细调用与数据关系见 [工程结构报告](工程结构详细报告_2026-11-12.md)。本文按运行职责列目录，不是文件清单。名称和说明遵循 [术语与用词规范](术语与用词规范.md)，项目概念见 [CONTEXT.md](../CONTEXT.md)。产品定位是文字驱动的开放世界探索游戏；工程名后续可能更换。

## 总览

```text
浏览器 (app/static)
    ↓
FastAPI (app/main.py → app/web.py)
    ↓
Service（回合协调、模型调用）
    ↓
Runtime（旅程状态、行动结算、玩家可见信息）
    ↓
Store / 故事包文件 / 地图导入
```

规则先计算行动结果；模型叙述时只收到已经确定、允许公开的信息。

## 启动与入口

| 模块 | 位置 | 职责 |
|---|---|---|
| 应用入口 | `app/main.py` | 创建 FastAPI 应用 |
| HTTP 与页面 | `app/web.py` | 玩家 API、作者 `/api/inner/*`、静态页 |
| 一键启动 | `tools/bootstrap.py`，`启动.cmd` / `新安装并启动.cmd` / `停止服务.cmd` | 探测 Python、装依赖、选端口、起服务 |
| 数据校验 | `app/contracts.py`、`app/models.py` | 请求体与故事结构校验 |

## 旅程核心

| 模块 | 位置 | 职责 |
|---|---|---|
| 服务层 | `app/service.py` | 准备模型输入、调用模型，失败时不保存结果 |
| 运行时 | `app/runtime.py` | 包版本、回合、移动、行动后果及玩家可见信息 |
| 存档 | `app/storage.py` | 保存 SQLite 数据、检查修订号，分别记录世界事实、角色认知与玩家所闻 |
| 包事务 | `app/package_transaction.py` | 协调故事包文件与数据库的保存，支持中断恢复 |
| 模型适配 | `app/provider.py`、`app/prompts.py`、`prompt_templates/` | 请求、超时、用量 |
| 笔记锁 | `app/file_locks.py` | 防止多个进程同时重建笔记 |

## 知识与内容

目标职责见 [故事包定义与层级](story-package-definition.md)：故事包整合世界背景，城镇生成在其下一级补充聚落与道路。背景目标已独立生成和发布；旧城市与事件生成保留兼容入口，下级已接聚落选址、道路规划、单镇细化与王国版本发布；道路规划不表示历史上已建成。

| 模块 | 位置 | 说明 |
|---|---|---|
| 设定资料库 | `app/encyclopedia.py`、`tools/encyclopedia_build.py` | 可复用的待审资料；分类数量由建库参数决定 |
| 资料选择与采用 | `app/element_assembly.py` | 固定资料版本并纳入故事包 |
| 世界设定 / 草稿 | `app/world_setting.py`、`app/ai_drafts.py`、`app/world_package_pipeline.py` | 作者生成与确认 |
| 世界背景版本 | `app/background_package.py` | 组合库资料、保存采用资料的固定副本、分批生成背景、审核发布并提供城镇输入 |
| 内容目录 | `docs/element-catalog/`、`docs/human-encyclopedia/` | 候选素材，不是工程完成度 |

## 地图与世界

| 模块 | 位置 | 说明 |
|---|---|---|
| 玩家地图 | `app/play_map.py`、`app/play_map_world.py`、`app/map_policy.py` | 默认 `world_map_product`；服务端裁剪与迷雾，civ-atlas 显式开启 |
| 作者地图数据 | `app/map_bundle.py`、`app/map_bundle_routes.py`、`config/map-bundles.json` | 六组固定来源、月份、地点与矩形区域查询、分批读取地图线条；不切换玩家默认地图 |
| civ-atlas 导入 | `app/map_import.py`、`app/civ_atlas/` | 默认关闭；旧 `app.civ_atlas_*` 等路径为兼容入口 |
| 探索旅行 | `app/civ_atlas/exploration.py`、`app/adventure_actions.py` | civ 道路/街区及作者声明路线；TG 陆路网络未接 |
| 统一地形读取 | `app/map_source/` | 统一读取已保存地图数据，并保留来源检查和缓存 |
| 世界生成 | `app/world_gen/` | 基础地形、岛链、岛屿山地、快速地形与后台生成任务 |
| 地形细节 | `app/world_relief/` | TD / 侵蚀 / 图册等；局部高精度 |
| Terragenesis 调用 | `app/world_gen/terragenesis_bridge.py` | 查找并调用相邻 Terragenesis 工程；计算量大的步骤使用独立 Python 环境 |
| 王国聚落与道路规划 | `app/kingdom_settlements.py` | 固定背景和陆地疆域内选址与寻路、来源核对、复用单镇生成及发布不可变王国版本 |
| 城镇规则 | `app/towns.py`、`app/towns_store.py`、`app/town_plan.py`、`app/town_layout*.py` | 四阶段 + 布局预览 |
| 背景地理与疆域 | `app/background_geography.py` | 按原始网格统计环境，识别连通陆地，计算背景年份的陆地疆域并记录参数来源 |
| 文明模拟 | `app/civ_sim/`、`tools/run_civ_sim.py` | 可居住网格与模拟历史；历史预览经 `world_history_store.preview_civ_sim`；见 [civ-sim.md](civ-sim.md) |
| 建筑经营标记 | `app/building_economy.py` | 尚未参与回合结算 |

世界层现行规则：[terrain-generation-rules.md](terrain-generation-rules.md) 第 6 节。岛链 / 岛山：[ocean-island-integration.md](ocean-island-integration.md)、[island-mountains.md](island-mountains.md)。

## 前端

| 区域 | 位置 | 说明 |
|---|---|---|
| 主站 | `app/static/index.html`、`app.js`、`play-ui.js`、`playable-demo.js` 等 | 多脚本直挂 `window`，无根目录前端构建 |
| 作者王国城镇 | `kingdom-settlements.js` | 选择背景与国家、检查聚落和规划道路、补齐输入、编辑单镇与发布王国版本 |
| 作者城镇 | `towns.js`、`town-plan-ui.js` | 草稿与布局预览 |
| 作者世界背景 | `background-generator.js`、`background-generator.css` | 选地图、组合设定、模拟、审阅、发布与修订；背景包不直接游玩 |
| 作者地图 | `map-bundle.js`、`map-bundle.css` | 已登记同源产品的图层、月切换和点检 |
| 骰子 | `dice.js` | 展示以服务端结果为准 |
| 天气预览 | `app/static/weather-fx/` | 独立页，未挂主站 |
| 地图素材 | `app/static/map-art/` | 目录 README 只说明画法；接入见进度文档 |

civ-atlas 地图运行组件的生成文件在 `dist-dream/`（构建自 `external/civ-atlas`，目录通常被忽略）。

## 数据与故事

| 路径 | 用途 |
|---|---|
| `saves/` | 正式 SQLite 数据库、导入地图及笔记写入锁 |
| `StoryPackage/` | 旧可玩包 `story.json`；新背景包 `背景_bgv_*/background.json` 与知识文档；`kingdoms/ksv_*.json`保存独立王国城镇版本 |
| `character_packages/` | 独立角色包 |
| `artifacts/` | 建库结果、生成文件和验证记录（多数不纳入 Git） |
| `DreamTerra/` | 独立的有限世界实现；由 `web.py` 提供作者接口及对应玩家可见信息 |
| `tests/` | 离线测试；不同批次数字不能相加 |
