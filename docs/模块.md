# 织梦模块说明

更新日期：2026-11-12。对应进度见 [工程进度.md](工程进度.md)，详细调用与数据关系见 [工程结构报告](工程结构详细报告_2026-11-12.md)。本文按运行职责列目录，不是文件清单。产品定位是文字驱动的开放世界探索游戏；工程名后续可能更换。

## 总览

```text
浏览器 (app/static)
    ↓
FastAPI (app/main.py → app/web.py)
    ↓
Service（回合协调、模型调用）
    ↓
Runtime（旅程状态、行动结算、投影）
    ↓
Store / 故事包文件 / 地图导入
```

规则在引擎里结算；模型只在叙述阶段拿到已经裁定过的公开投影。

## 启动与入口

| 模块 | 位置 | 职责 |
|---|---|---|
| 应用入口 | `app/main.py` | 创建 FastAPI 应用 |
| HTTP 与页面 | `app/web.py` | 玩家 API、作者 `/api/inner/*`、静态页 |
| 一键启动 | `tools/bootstrap.py`，`启动.cmd` / `新安装并启动.cmd` / `停止服务.cmd` | 探测 Python、装依赖、选端口、起服务 |
| 契约 | `app/contracts.py`、`app/models.py` | 请求体与故事结构校验 |

## 旅程核心

| 模块 | 位置 | 职责 |
|---|---|---|
| 服务层 | `app/service.py` | 组织上下文、调模型、失败不落盘 |
| 运行时 | `app/runtime.py` | 包版本、回合、移动、效果、surface 投影 |

| 笔记锁 | `app/file_locks.py` | 跨进程笔记重建互斥 |

## 知识与内容

目标职责见 [故事包定义与层级](story-package-definition.md)：故事包整合世界背景，城镇生成在其下一级补充聚落与道路。背景目标已独立生成和发布；旧城市与事件生成保留兼容入口，下级城镇与路网生成尚未完成。

| 模块 | 位置 | 说明 |
|---|---|---|
| 百科 | `app/encyclopedia.py`、`tools/encyclopedia_build.py` | 候选库；组数看构库参数 |
| 元素装配 | `app/element_assembly.py` | 锁版本进故事包 |
| 世界设定 / 草稿 | `app/world_setting.py`、`app/ai_drafts.py`、`app/world_package_pipeline.py` | 作者生成与确认 |

| 内容目录 | `docs/element-catalog/`、`docs/human-encyclopedia/` | 候选素材，不是工程完成度 |

## 地图与世界

| 模块 | 位置 | 说明 |
|---|---|---|
| 玩家地图 | `app/play_map.py`、`app/play_map_world.py`、`app/map_policy.py` | 默认 `world_map_product`；服务端裁剪与迷雾，civ-atlas 显式开启 |
| 作者同源地图 | `app/map_bundle.py`、`app/map_bundle_routes.py`、`config/map-bundles.json` | 六组冻结来源、月份、点值/格窗/分页矢量；不切换玩家默认 |
| civ-atlas 导入 | `app/map_import.py`、`app/civ_atlas/` | 默认关闭；旧 `app.civ_atlas_*` 等路径为兼容 shim |
| 探索旅行 | `app/civ_atlas/exploration.py`、`app/adventure_actions.py` | civ 道路/街区及作者声明路线；TG 陆路网络未接 |
| 统一地形读取 | `app/map_source/` | 作者和玩家读取冻结产品的契约、适配器与缓存 |
| 世界生成 | `app/world_gen/` | 骨架、岛链、岛山、快速世界层、Web 任务 |
| 地形细节 | `app/world_relief/` | TD / 侵蚀 / 图册等；局部高精度 |
| TG 内核桥 | `app/world_gen/terragenesis_bridge.py` | 同级 Terragenesis 工程探测与内核边界；重型阶段经独立解释器运行 |
| 城镇规则 | `app/towns.py`、`app/towns_store.py`、`app/town_plan.py`、`app/town_layout*.py` | 四阶段 + 布局预览 |
| 背景地理与疆域 | `app/background_geography.py` | 原生网格摘要、连通陆块 ID、背景年 LAND 裁剪疆域和参数来源 |
| 文明模拟 | `app/civ_sim/`、`tools/run_civ_sim.py` | 栖居栅格、编年史；历史预览经 `world_history_store.preview_civ_sim`；见 [civ-sim.md](civ-sim.md) |
| 建筑经营标记 | `app/building_economy.py` | 未进回合结算 |

世界层现行规则：[terrain-generation-rules.md](terrain-generation-rules.md) 第 6 节。岛链 / 岛山：[ocean-island-integration.md](ocean-island-integration.md)、[island-mountains.md](island-mountains.md)。

## 前端

| 区域 | 位置 | 说明 |
|---|---|---|
| 主站 | `app/static/index.html`、`app.js`、`play-ui.js`、`playable-demo.js` 等 | 多脚本直挂 `window`，无根目录前端构建 |
| 作者城镇 | `towns.js`、`town-plan-ui.js` | 草稿与布局预览 |
| 作者世界背景 | `background-generator.js`、`background-generator.css` | 选地图、组合设定、模拟、审阅、发布与修订；背景包不直接游玩 |
| 作者地图 | `map-bundle.js`、`map-bundle.css` | 已登记同源产品的图层、月切换和点检 |
| 骰子 | `dice.js` | 展示以服务端结果为准 |
| 天气预览 | `app/static/weather-fx/` | 独立页，未挂主站 |
| 地图素材 | `app/static/map-art/` | 目录 README 只说明画法；接入见进度文档 |

原生 civ-atlas 宿主产物在 `dist-dream/`（构建自 `external/civ-atlas`，目录通常被忽略）。

## 数据与故事

| 路径 | 用途 |
|---|---|
| `saves/` | 正式 SQLite、导入地图、笔记锁 |
| `StoryPackage/` | 旧可玩包 `story.json`；新背景包 `背景_bgv_*/background.json` 与知识文档 |
| `character_packages/` | 独立角色包 |
| `artifacts/` | 构库、生成产物、验收证据（多数已忽略） |
| `DreamTerra/` | 有限世界旁路；仍由 `web.py` 注册作者 API，相关故事可分流到其玩家投影 |
| `tests/` | 离线测试；不同批次数字不能相加 |
