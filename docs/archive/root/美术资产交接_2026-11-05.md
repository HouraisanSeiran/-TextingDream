## 2. 物品属性图示 `game-icons`

- 文件：`app/static/item-art/game-icons.svg`（sprite）、`game-icons.json`（取值 → symbol 对照）。
- 风格：墨线描边加淡彩，沿用 `map-art-medieval.svg` 的配色；每格 24×24，16 px 下仍可辨认。产地底色取自 civ-atlas 群落水彩色（`external/civ-atlas/src/gen/biomes.ts`）。
- id 前缀 `gi-`，避免和地图 sprite 的 `res-` / `town-` 冲突。

| 组 | 数量 | 取值 |
|---|---|---|
| 货币（价格档） | 7 | 法寻、便士、格罗特、先令、镑、禁售、无价 |
| 产地 | 24 | 14 个群系 + 山地、高原、海岸、河流 + 农田、果园菜圃、牧场、矿坑、作坊厨房、远途输入 |
| 季节 | 5 | 春、夏、秋、冬、全年 |

- 对照表的键与 `tools/game_fields.py` 的词表一一对应，测试 `tests/test_game_icons.py` 保证缺图、多图、指错都会失败。
- 用户反馈后改过：热带雨林（改为单棵树构图）、苔原（加绿苔、矮灌丛与水洼）、高原（新增，背景雪峰 + 平顶台地）。
- 样张：`node tools/game_icons_sheet.cjs` → `artifacts/game-icons/game-icons-sheet.png`。

**待处理**：工程已改为十进制货币（`docs/units.md`：10 铜币 = 1 银币，10 银币 = 1 金币，先令、镑不再使用）。这 7 个货币图标仍按旧的便士 / 先令 / 镑画，价格档名也还是旧的。要等价格档词表改完，再重画货币图标。
