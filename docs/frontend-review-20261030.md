# 前端建议核对与落实

依据：仓库根《前端代码分析与改进建议.md》。核对日期：2026-10-30。

## 结论

文档适合作为改进方向，但混合了真实问题、已有能力和未测量的收益预测。此次按实际代码落实一轮改进；不是完成文档所列两个月的全库重构。

织梦正在使用的是 `src/dream/entry.tsx → host.tsx`，不是上游完整的 `ui/App.tsx`。两者均保留，本轮重点修复实际宿主，并为上游入口补错误边界、拆出 URL 解析。

## 逐项核对

| 文档建议 | 核对结果 | 本轮处理 |
| --- | --- | --- |
| 统一状态管理，迁移 Zustand | `civView.ts` 等已采用 React `useSyncExternalStore`；没有库不等于状态管理错误。持久化整个 World 还涉及类型数组、容量和现有存档协议 | 保留现有状态源；把宿主世界清单/原件读取提取为 `useNativeWorlds`，独立清理过期请求，提供真实重试 |
| 拆分 App | App 仍约 380 KB，大文件问题成立；它同时协调地图、模拟、编辑，并非三个互斥页面 | 抽离 `appLocation.ts` 并验证旧链接兼容；实际宿主拆出 `WorldMapCanvas`、`WorldGenerationForm`、数据读取和宿主 API 边界。未声称完成 App 的全面拆分 |
| CSS 模块化、设计令牌 | `ui/styles.ts` 已按功能引入多份 CSS，`theme.css` 已有颜色、字体等变量 | 新增错误面板和地图焦点样式采用 CSS Modules；复用现有风格。修复地图外壳样式依赖未提供的 `/dreamterra/` 地址，改由主工程 `/static/civ-atlas.css` 提供 |
| Worker、虚拟列表、延迟加载 | 已有生成、导出、地球仪等 Worker；Boot 已延迟加载 App。编年史确实完整渲染当前列表，但还依赖 DOM 实现时间线跳转 | 修复实际浪费：地形底图与文明底图分离，图层切换不再重画地形。没有测量依据支持“性能提升 30–50%”；虚拟列表需连同跳转与当前年份定位改造，本轮未迁移 |
| TypeScript 严格检查、Zod | `strict: true` 已开启，宿主确有 `any` 和未经检查的 API 响应 | 为宿主注入接口添加类型，异常用 unknown；清单和元数据检查形状，错误响应不会变成空清单；创建旅程检查草稿/旅程编号。复用元数据读取，移除生成流程中重复的无类型解析。未全库清除 any |
| 错误边界 | 两个入口原本均没有 React 错误边界，rAF 异常也不能由普通边界自动捕获 | 两个入口增加边界；地图局部独立重绘重试，rAF/字体异步失败转入边界。重试地图保留宿主选择与草稿，不重启生成或创建旅程 |
| 可访问性 | 上游已有快捷键等能力，宿主地图缺少键盘操作 | 地图可聚焦；加减缩放、方向键平移、0 复位；输入控件和修饰键不被抢占；图层/缩放有分组语义，进度有名称，焦点可见 |
| 测试不足 | 项目已有 Vitest、真实浏览器和 Python 契约测试，不能称“缺少测试” | 补 13 项 URL/参数/API 边界测试、故障恢复与键盘/窄屏浏览器验收，更新原件切换测试以接受卸载旧画布；补递归安装补丁验证 |

文档中的目录树、Zustand/Tailwind 示例和维护效率百分比没有直接作为实现要求照搬。也没有全局打开 `noUncheckedIndexedAccess` 等选项后用类型断言掩盖错误。

## 额外发现并修复的直接问题

- “随机种子”原先重置所有生成参数，现只更换种子。
- 清空数值输入原先变成 0，现保持空值，必填校验阻止提交；创建 Worker 前再次校验有效范围和整数字段。
- 世界清单/原件读取失败没有原位重试，现分别重试对应请求；过期响应的成功、失败均不覆盖当前世界。
- 安装器只复制三个早期导出文件，新组件在干净安装中会缺失。现按补丁目录的相对路径复制全部文件；测试确认未列入补丁的生成算法文件不受影响。
- 旧契约测试仍要求玩家显示 `not_ready`，但玩家地图已经使用独立宿主。更新该过时断言，保留真实浏览器的玩家不访问作者路由验证。

## 验证与边界

- TypeScript 类型检查通过。
- 13 项 Vitest 测试通过。
- 原生宿主构建、上游完整生产构建通过；上游仍提示 App 等大块超过 500 KB，未通过提高阈值隐藏提示。
- 24 项相关 Python 检查通过，覆盖数据桥、原件切换/迟到响应、玩家隔离和补丁安装/打包。首次发现的过时占位断言已更新，所属 7 项打包检查复跑通过。
- 主工程浏览器验证：清单失败后恢复、绘图异常后单独重试、键盘缩放/平移/复位、随机种子保留参数、空值阻止提交、输入框按键不误触地图、390 px 窄屏。证据在 `artifacts/frontend-improvements/`。
- 本轮没有重生成世界、推进用户旅程或启动 llama。DreamTerra 地形生成与地图算法未修改。

后续仍有明确剩余项：上游 App 的世界生命周期/模拟控制继续拆分，编年史虚拟化与定位联动，全库类型检查增强及完整无障碍审计。本轮不将这些标为完成。
