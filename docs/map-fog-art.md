# 地图迷雾的美术实现（灰蓝卷云墙）

> **依据**：本文的视觉目标来自用户提供的《天国：拯救》系列地图截图（两张，作为**风格参考**）。
> 本轮**没有**联网核实任何资料，也没有裁切/嵌入参考图素材或水印；所有云都是代码实时画的。

## 分工：安全在服务端，美术在客户端

| 部分 | 文件 | 职责 |
|---|---|---|
| 安全 | `app/fog_art.py` | 揭示圈外底图像素 = 单一常量 `FOG_RGB`（不随位置变、不读地形）；rough edge（0.80–0.97）随投影 JSON 下发 |
| 几何 | `app/play_map.py` → `fog.reveal` / `fog.cloud_deg` | 圆心、半径、64 点 edge 轮廓、云的尺度量 |
| 美术 | `app/static/map-fog.js`（`TDMapFog.paint`） | 在底图上方画卷云墙，**只读 ratio 与 cloud_deg** |
| 接入 | `app/static/play-ui.js` | 拖动/缩放时先 CSS 变换跟随，停下后重画 |

`TDMapFog` 接口保持不变：`paint(canvas, {box, reveal, cloudDeg, rect, scale})`，
外加 `ratioAt(lon, lat, reveal)` 与常量 `OPAQUE_AT / CLEAR_AT / INNER_CLEAR / EDGE_AT`。

## 硬约束（有测试盯着）

1. `ratio >= 0.985` → **alpha 恒为 255**（完全不透明），不看云画到哪儿；
2. `ratio <= 0.93` → 一个像素都不画（可见区里没有装饰）；
3. 中间那道雾边只向内收（噪声只作用在 ratio 上，幅度小于余量）；
4. 底图矩形以外不画任何像素；
5. 服务端绝不发送雾下地形（`tests/test_fog_art.py` 用两种地形各画一次比对字节）。

回归测试：`tests/test_fog_alpha.py`（Node 沙箱里跑真代码 + mock canvas）覆盖
**三地区 × zoom 1/2（底图缩放）× dpr 1/2（设备像素比）× 单圆/全部圆**，共 24 个场景，
逐像素比对 alpha 与 ratio；另有 `tests/test_fog_art.py`（服务端）与 `tests/test_map_clues.py`。

两档不变量都验：

- `ratio >= 0.985` 必须 alpha=255（硬约束）；
- `ratio >= 1`（揭示圆外）也必须 alpha=255（更严）；
- 底图矩形外不得有任何非零 alpha；
- 可见区内 alpha>0 的像素占比（`insideCoveredPct`）必须 <50%，证明雾只在贴边一圈。

## 怎么画的

云是**沿探索边界的极坐标云岸**，不是散在平面的气泡：格子按（方位角弧长, 离边界距离）分，
所以一圈云自然成排、成片、大体成圆；每片云的形状由世界坐标的种子与域扭曲决定，
所以换到哪个地区都是全新的一片，但总体仍是近圆。

三层由远及近叠（后面的云被前面的盖住）：

| 层 | 位置（d = ratio‑1） | 形态 | 颜色 |
|---|---|---|---|
| 0 | 0.28 – 3.30 | 最大、最暗的云层 | 灰褐 / 炭灰（`PAL_*[0]`） |
| 1 | ‑0.02 – 1.15 | 中尺度云岸（与上下两层大幅重叠） | 深灰蓝（主体） |
| 2 | ‑0.03 – 0.095 | 贴地图的细小扇贝云缘（窄，时隐时现） | 浅灰蓝 |

每层还有一个**方位角低频调制**（`wob`，几个以 2π 为周期的谐波）：把这层的“离边界多远”
按方位高低错开，否则每层都沿着 ratio 等值线成排，一整圈就是一道环形轨道。

细节：

- 每团云 = 3–5 个高斯球融合的 metaball 云岸，径向压扁；只在**整道云的外轮廓**描一道细墨线
  （越靠地图越实、越深越淡、有时断笔），不会把每颗小球描成一个圆圈；
- 云体明暗只看「云体多厚（场值）+ 迎光面」，不叠像素级晕染；
- 云内部一层很淡的卷云细弧：相位来自低频率的域扭曲场，取 sin 窄带 + 断续阈值，所以是弯的短弧；
- 雾边**不**描那圈“细墨 + 亮边”的双线（否则近缘就是一道环形道路）；
- 越往外天空越暗（深灰蓝，不是平黑），最上面一层极轻的纸纹；
- 所有噪声都取**世界坐标**，所以地图平移/缩放时云不跳；按地区改变冷暖与云量。

性能：云场在粗网格（≈1.5–3 设备像素）上算、再双线性插值；ratio 逐列只算一次并存成行缓存
（不用粗网格插值 ratio：那会在阈值处产生不连续的台阶边界）。
实测（Edge headless，DPR=2，640×440 CSS）：缩放 1 约 490–600 ms，缩放 2 约 810–1030 ms 一帧。

  与雾无关）；所有页面资源的 response 状态均为 200（`resourceErrors` 为空）。

## 没做的

- 没有动画（云不飘）；
- 没有把雾预烘成贴图缓存（目前每帧重算，已靠粗网格控成本）；
- 没有改可见权限、资源、城镇规则，也没动外部地图引擎与用户 `data/`。
